# 吾爱直播 iOS 1.0.2 网页封装修复版

基于正在使用的 1.0.1 Build 2 升级为 1.0.2 Build 3。入口为 https://jiami.ttplays.uk:6067/，包名 com.chatapp.bqimvip，最低 iOS 16，iPhone arm64。

本版本仅使用 UIKit 与 WKWebView。保留原启动画面、Logo、图标、Cookie 存储、输入框缩放修复及横竖屏桥接；没有 VLC 或其他播放器依赖。PreservedResources 是从用户提供的原 IPA 中提取的品牌和启动资源，不包含证书、私钥或描述文件。

## 修复行为

- 忽略 NSURLErrorDomain 的 -999 取消事件，不弹窗、不重试，不将其误报为网络故障。
- 首页及应用发起的重试使用至少 120 秒的请求空闲超时。页面内导航保持 WebKit 的请求语义；不重建表单请求。
- 主页面临时网络错误对 GET 和 HEAD 最多自动重试两次，间隔 2 秒和 5 秒；新导航取消旧重试，迟到的旧导航错误不影响新页面。
- 真正失败时显示可关闭的页面内提示，并重试原请求，不强制返回首页。POST 等提交请求不自动重放，返回原页面核对后操作。
- 冷启动继续显示原品牌画面至少 1 秒；主文档提交后淡出，避免慢图片等子资源延迟阻挡页面显示。
- 新窗口链接只加载一次；Cookie、缓存、TLS 校验与网站播放方式保持原有配置。

## 构建

GitHub Actions 使用 macos-15 和 Xcode 16.4，Release / iphoneos / arm64。先运行 Swift 恢复策略回归，再编译并核对版本和原版素材。

`bash build-release.sh` 构建默认输出未签名 IPA。如果设置 IOS_P12_BASE64、IOS_PROFILE_BASE64、IOS_P12_PASSWORD 环境变量，则在临时钥匙串中签名并验证后输出已签名 IPA。敏感值只能从 GitHub Actions Secrets 注入，不写入源码或日志。

## 真机验收

构建和策略测试不能代替真实设备验收。覆盖慢网冷启动、加载中快速点链接、断网重连、加载失败后重试、登录及支付跳转、播放与横竖屏、图标与启动页、旧版覆盖安装和登录状态保留。

本分支的 1.0.2 是纯网页封装修复版，与历史 VLC 试验分支的同名版本用途不同。
